# 🎮 เกมทบทวนบทเรียน — Kaka & Sheva

เกมทบทวนบทเรียนสำหรับลูก เล่นบนมือถือ/แท็บเล็ต/คอมได้ **ฟรี 100%** ไม่มีค่า server
Kaka (ป.2) 8 วิชา + Sheva (ป.1) 8 วิชา รวม **16 วิชา · 711 ข้อ · 79 ด่าน** + ด่านจับคู่คำศัพท์อีก 18 ชุด
เนื้อหาเป็นของ **สอบครั้งที่ 2 เท่านั้น** (ครั้งที่ 1 สอบจบไปแล้ว จึงเอาออก)
(เลือกโปรไฟล์ → เลือกวิชา → เล่นเป็นด่านๆ)

## 1. ลองเล่นในเครื่องก่อน (ไม่ต้อง setup)

**ดับเบิลคลิกไฟล์ `index.html`** → เปิดในเบราว์เซอร์ (Chrome/Edge) เล่นได้เลย
เหมาะกับทดสอบก่อนเอาขึ้นเว็บจริง

> เล่นในเครื่องได้เพราะข้อมูลเก็บเป็นไฟล์ `.js` (ไม่ใช่ `.json` ที่เบราว์เซอร์จะบล็อกตอนเปิดแบบ file://)

## 2. เอาขึ้นเว็บฟรี ให้ลูกเปิดจากมือถือได้ทุกที่

### วิธี A — Netlify Drop (ง่ายสุด ไม่ต้องสมัครก็ได้) ⭐ แนะนำ

1. เปิดเว็บ **https://app.netlify.com/drop**
2. **ลากโฟลเดอร์ `web` ทั้งโฟลเดอร์** ไปวางในหน้านั้น
3. รอสักครู่ จะได้ลิงก์ เช่น `https://ชื่อสุ่ม.netlify.app` → เปิดบนแท็บเล็ตลูกได้เลย
4. อยากเก็บลิงก์ถาวร/ตั้งชื่อเอง → สมัครบัญชีฟรี (ใช้ Google login) แล้วกด "Claim this site"

> อัปเดตเนื้อหาใหม่: แก้ไฟล์ แล้วลากโฟลเดอร์ `web` ไปวางใหม่อีกครั้ง (ทับของเดิม)

### วิธี B — GitHub Pages (ถ้ามีบัญชี GitHub อยู่แล้ว)

1. สร้าง repo ใหม่ → อัปโหลดไฟล์ในโฟลเดอร์ `web` ทั้งหมด
2. Settings → Pages → Source เลือก branch `main` โฟลเดอร์ `/root` → Save
3. ได้ลิงก์ `https://ชื่อคุณ.github.io/ชื่อ-repo/`

### วิธี C — Cloudflare Pages
คล้าย GitHub Pages เชื่อมกับ repo แล้ว deploy อัตโนมัติ (ฟรี)

**ทุกวิธีข้างบนฟรีถาวร** ค่าใช้จ่ายเดียวที่ *อาจ* มีคือชื่อโดเมนสวยๆ (~300 บาท/ปี) ซึ่งไม่จำเป็น

## 3. บันทึกความคืบหน้า (สำคัญ)

- เหรียญ / ดาว / สติกเกอร์ / streak เก็บไว้ใน **เบราว์เซอร์ของเครื่องที่เล่น** (localStorage)
- **ผูกกับเครื่อง + เบราว์เซอร์นั้น** → ถ้าเล่นคนละเครื่อง/คนละเบราว์เซอร์ จะเริ่มใหม่
- **ย้ายเครื่องได้** ด้วยโค้ดเซฟ (ดูข้อ 6) — ไม่ต้องเริ่มใหม่
- อย่ากด "ล้างข้อมูลเบราว์เซอร์/ประวัติ" เพราะจะลบความคืบหน้า

| ระบบ | ทำอะไร |
|------|--------|
| 🦊 เพื่อนคู่ใจ (Buddy) | เลือกตัวการ์ตูน คอยเชียร์ตอนเล่น โตขึ้นเมื่อเล่นเยอะ |
| 🗺️ แผนที่ด่าน | วิชาละ 4–5 ด่าน แต่ละด่านมี **คลังข้อ 9 ข้อ แล้วสุ่มมาเล่น 6 ข้อ** ผ่านแล้วปลดล็อกด่านต่อไป |
| 🎲 เล่นซ้ำไม่ซ้ำเดิม | ทุกครั้งที่เข้าด่าน เกม**สุ่มข้อใหม่ + สลับตำแหน่งตัวเลือก** — จำว่า "ตอบข้อ ง." ไม่ช่วย |
| ⭐ ดาว 1-3 ดวง | คะแนนของด่านนั้น (ตอบถูกยิ่งเยอะยิ่งได้ดาว) เล่นซ้ำเพื่อไล่เก็บ 3 ดาวได้ |

| 🪙 เหรียญ + คอมโบ | ตอบถูกได้เหรียญ ตอบถูกติดกัน 3 ข้อ = คอมโบ x2 |
| 🎁 ตู้สะสมสติกเกอร์ | เอาเหรียญเปิดกล่องสุ่ม เก็บสติกเกอร์ 20 แบบ (มีระดับหายาก) |
| 🔥 รางวัลรายวัน | เข้าเล่นทุกวันได้โบนัสเหรียญเพิ่มขึ้นเรื่อยๆ |
| 💪 ด่านทบทวน | รวมข้อที่เคยตอบผิด ให้ทบทวนซ้ำจนแม่น (ขึ้นทันทีที่ตอบผิด ไม่ต้องรอจบด่าน) |
| 🔤 จับคู่คำศัพท์ | ด่านพิเศษบนแผนที่วิชา **English / Math (Inter) / Science (Inter)** — แตะคำซ้ายจับคู่กับคำขวา |
| 🎁 แลกของรางวัลจริง | สะสมดาว → แลกของเล่นที่พ่อแม่กด PIN ยืนยัน (ดูข้อ 5) |
| 🔊 อ่านให้ฟัง | ทุกคำถามมีปุ่มอ่านออกเสียง (ไทย/อังกฤษ auto) — ช่วยลูกที่อ่านยังไม่คล่อง |

คำถามมี 5 แบบ: **เลือกตอบ** · **เติมคำ (แตะเลือกคำ)** · **จำแนกลงกล่อง** · **เรียงประโยค (แตะเรียงคำ)** · **จับคู่คำศัพท์**

### 🛡️ กันเด็กกดมั่วแล้วแอบดูเฉลย

เดิมลูกกดมั่ว → เกมเฉลยให้ → กดปุ่มย้อนกลับหนี → เข้าใหม่ได้ข้อเดิมเรียงเดิม แล้วกด 3 ดาวเต็ม ตอนนี้ปิดช่องนี้แล้ว 3 ชั้น:

1. **ตอบผิดปุ๊บ บันทึกปั๊บ** — ข้อที่ผิดถูกเก็บทันที (ไม่รอจบด่าน) หนีออกยังไงก็ยังโผล่ในด่านทบทวน 💪 และในสรุปของพ่อแม่
2. **ออกกลางด่าน = ยังไม่ผ่าน** — กดย้อนกลับจะมีกล่องถามยืนยันก่อน ถ้ายืนยันออก **เหรียญที่ได้ในด่านนั้นถูกคืนหมด** (ปิดแท็บหนีก็คืนเหมือนกัน) และนับไว้ให้พ่อแม่ดูว่าออกกลางด่านกี่ครั้ง
3. **เข้าใหม่ได้ข้อใหม่** — สุ่มข้อจากคลังใหม่ + สลับตำแหน่งตัวเลือก จำเฉลยเดิมมาใช้ไม่ได้

## 5. ⭐ ธนาคารดาวความดี + แลกของรางวัลจริง (พ่อแม่ควบคุม)

เชื่อมกับระบบที่บ้าน (สะสมดาว → แลกของเล่น) ให้ลูกอยากทบทวนบทเรียน

**ดาวมาจาก 2 ทาง รวมเป็น "ธนาคารดาว" เดียว (แยกของแต่ละคน):**
1. **จากเกม** — **1 ด่านเต็มดาว = 1 ⭐** เข้าธนาคารอัตโนมัติ · เต็มดาวคือ **ตอบถูกครบทุกข้อในด่านนั้น** · ตอบถูก 4-5 ข้อจาก 6 ยังผ่านด่านและปลดล็อกด่านต่อไปได้ แต่**ไม่ได้ ⭐ สะสม** ต้องกลับมาทำจนเต็ม · ด่านที่เคยเต็มดาวแล้วเล่นซ้ำไม่ได้ ⭐ เพิ่ม (กันปั๊มดาว)

   > ⭐ หายากโดยตั้งใจ — เพราะคำถามถูกสุ่มจากคลัง 9 ข้อและสลับตัวเลือกทุกครั้ง การจะตอบถูกครบ 6/6 แปลว่าลูก**แม่นทั้งด่านจริงๆ** ไม่ใช่จำเฉลยได้
2. **จากพ่อแม่** — เข้าโหมดพ่อแม่ เพิ่มดาวเองสำหรับความดีนอกเกม (ช่วยงานบ้าน ฯลฯ)

**การแลกรางวัล:**
- เด็กเห็นยอดดาว + หลอดความคืบหน้า "อีกกี่ดาวได้ของเล่น" ตลอดเวลา (สร้างแรงจูงใจ) และกด **"ของรางวัล 🎁"** ดูได้
- ดาวครบ → กด **"ขอแลกรางวัล"** → **ต้องใส่ PIN ของพ่อแม่** ถึงจะแลกสำเร็จ (ดาวจะถูกหักออก + บันทึกประวัติ)
- ค่าเริ่มต้น: **ของเล่น 100 บาท = 10 ดาว** (ตรงกับระบบเดิมที่บ้าน)

**📊 สถิติการเล่น (ปุ่มแรกในโหมดพ่อแม่):**

หน้าสรุปว่าลูกเล่นอะไรไปบ้าง ตอบถูกแค่ไหน — แยกของแต่ละคน

- **สรุป 4 ตัวเลข** — ตอบไปกี่ข้อ (+เวลารวม) · ตอบถูกกี่ % · **เวลาเฉลี่ยต่อข้อ** · เข้าเล่นกี่วัน
  - ช่อง "ตอบถูก" มีบรรทัด **▲/▼ เทียบ 7 วันก่อน** — ตอบคำถามว่า *ที่ติวไปได้ผลไหม*
  - ถ้าเฉลี่ย **ต่ำกว่า 5 วินาที/ข้อ** จะขึ้นเตือน ⚡ ว่าน่าจะกดโดยไม่อ่านโจทย์
- **📝 ข้อที่ยังตอบผิดอยู่** — โชว์**คำถามจริง + เฉลย + คำอธิบาย** เรียงข้อที่ผิดซ้ำบ่อยสุดไว้บนสุด พร้อมป้าย "ผิดซ้ำ N ครั้ง" · เปิดอ่านแล้วนั่งติวกับลูกได้เลย ข้อจะหายไปเองเมื่อลูกตอบถูก
- **📚 เล่นวิชาไหนเยอะ** — แท่งเทียบกันตรงๆ เรียงมากไปน้อย พร้อม % ตอบถูกของแต่ละวิชา (✅ แม่นแล้ว ≥85% · ⚠️ พอใช้ 70-84% · ❗ ควรติว <70%) เวลาเฉลี่ยต่อข้อรายวิชา และบรรทัด **"ยังไม่เคยแตะเลย"** บอกวิชาที่ลูกหลบ
- **📅 14 วันล่าสุด** — กราฟว่าเล่นวันไหนบ้าง มากน้อยแค่ไหน (กดสลับดูเป็นตารางได้)
- **🎯 ด่านที่ควรติวก่อน** — 5 ด่านที่ตอบถูกน้อยที่สุด บอกชื่อหัวข้อชัดๆ ว่าควรทวนเรื่องไหน
- **🕐 เล่นตอนกี่โมง** — แบ่งเป็น เช้า/กลางวัน/เย็น/ค่ำ/ดึก · ถ้าเล่นช่วงดึก (22–05 น.) เกิน 25% จะขึ้นเตือน

> ⚠️ **สถิติเริ่มเก็บตั้งแต่เวอร์ชันนี้เป็นต้นไป** — ของเก่าที่เล่นไปแล้วย้อนหลังให้ไม่ได้ (เกมไม่เคยเก็บข้อมูลส่วนนี้มาก่อน) เปิดครั้งแรกจะขึ้นว่ายังไม่มีข้อมูล ให้ลูกเล่นสัก 1-2 ด่านก่อน
>
> เก็บอยู่ในเครื่องล้วน (localStorage) ไม่ส่งออกไปไหน · สถิติรายวันเก็บย้อนหลัง 120 วัน

**โหมดพ่อแม่ (ปุ่ม 🔒 ในหน้าของรางวัล — ต้องใส่ PIN):**
- **📊 สรุปจุดที่ควรติว** — โชว์วิชาที่ลูกยังพลาดบ่อย (เรียงมากสุดบนสุด) + จำนวนด่านที่ผ่าน + **จำนวนด่านที่ทำได้เต็มดาว (= จำนวน ⭐ ที่ได้จากวิชานั้น)** + **จำนวนครั้งที่ออกกลางด่าน** (ถ้าเลขนี้เยอะผิดปกติ แปลว่าลูกกดมั่วแล้วหนี ควรนั่งดูด้วยสักรอบ)
- เพิ่ม/ลดดาวเอง (พร้อมเหตุผล)
- ตั้งค่ารางวัล: เปลี่ยนชื่อ / emoji / จำนวนดาวที่ใช้แลก
- ดูประวัติทั้งหมด (ได้ดาวจากอะไร แลกอะไรไปบ้าง เมื่อไหร่)
- **♻️ รีเซ็ตความคืบหน้า** ของลูกคนนี้ (ล้างด่าน/ดาว เก็บ buddy — ใช้ตอนทดสอบเสร็จ)
- เปลี่ยน PIN

**การตั้ง PIN:** ครั้งแรกที่กดแลก/เข้าโหมดพ่อแม่ ระบบจะให้ตั้ง PIN 4 หลัก จำไว้ให้ดี

> **หมายเหตุความปลอดภัย:** PIN เก็บในเบราว์เซอร์แบบธรรมดา — มีไว้ "กันเด็กกดแลกเอง" พอ **ไม่ใช่ระบบกันแฮกจริงจัง** (คนที่รู้เทคนิคเบราว์เซอร์ยังข้ามได้) สำหรับใช้ในบ้านถือว่าเพียงพอ
>
> **ดาวสูงสุดจากเกม: ~49 ⭐/คน** (Kaka 49 · Sheva 48 — ด่านละ 1 ⭐ เมื่อทำได้เต็มดาว) — ที่ราคา **10 ⭐** เท่ากับต้องทำ **10 ด่านให้ได้เต็มดาว (ตอบถูกครบ 60 ข้อ)** ต่อของรางวัล 1 ชิ้น และเนื้อหาชุดนี้แลกได้ราว 5 ชิ้น
>
> ถ้ายังรู้สึกว่าเร็วไป ขึ้นราคาได้ในโหมดพ่อแม่ (15 ⭐ ≈ 3 ชิ้น · 20 ⭐ ≈ 2 ชิ้น) — แนะนำไม่เกิน 20 เพราะเลขใหญ่เกินไปเด็กจะรู้สึกไกลเกินเอื้อม

## 6. 📤 ย้ายเครื่อง (เซฟข้ามเครื่อง) — ไม่ต้องเริ่มใหม่

progress เก็บแยกแต่ละเครื่อง ถ้าจะย้าย iPad ↔ มือถือ ↔ คอม ใช้ "โค้ดเซฟ":

1. **เครื่องเก่า:** ของรางวัล → โหมดพ่อแม่ (ใส่ PIN) → การ์ด **"📤 ย้ายเครื่อง"** → กด **"สร้าง + คัดลอกโค้ดเซฟ"** (โค้ดจะถูกคัดลอกอัตโนมัติ หรือกดค้างเลือกคัดลอกเองก็ได้)
2. ส่งโค้ดไปเครื่องใหม่ (ผ่าน LINE/โน้ต/อีเมลตัวเอง)
3. **เครื่องใหม่:** เปิดเกม → ของรางวัล → โหมดพ่อแม่ → **วางโค้ดในช่องล่าง** → กด **"โหลดข้อมูลจากโค้ด"** (กดยืนยัน 2 ครั้ง)

> ย้ายทั้ง **ดาว/เหรียญ/ด่าน/สติกเกอร์/สถิติรายวิชา ของทั้ง 2 คน + PIN + ของรางวัล** · การโหลดจะ**เขียนทับ**ข้อมูลในเครื่องใหม่ · โค้ดเป็นข้อความยาวๆ (base64) ไม่ใช่รหัสลับ
>
> ⚠️ **โค้ดยาวหลักหมื่นตัวอักษร** (ยิ่งเล่นเยอะยิ่งยาว) — ให้วางในแอปโน้ต/อีเมลแล้วเปิดที่เครื่องใหม่ **อย่าส่งผ่านแชตที่ตัดข้อความยาว** (LINE จำกัด 10,000 ตัวอักษรต่อข้อความ) · กราฟ 14 วันไม่ย้ายตาม (ตัดออกเพื่อลดขนาดโค้ด) ที่เหลือไปครบ

## 7. 📱 เพิ่มลงหน้าจอโฮม + เล่นออฟไลน์

เปิดให้เหมือนแอปจริง มีไอคอน ⭐ บนหน้าจอ และ **เล่นได้แม้เน็ตหลุด** (เหมาะเวลาเดินทาง/ก่อนนอน)

- **iPhone/iPad (Safari):** เปิดเว็บ → ปุ่มแชร์ (⬆️) → **"เพิ่มลงในหน้าจอโฮม"**
- **Android (Chrome):** เปิดเว็บ → เมนู ⋮ → **"เพิ่มลงในหน้าจอหลัก" / "ติดตั้งแอป"**
- **คอม (Chrome/Edge):** ไอคอนติดตั้ง (⊕) ในแถบ URL

> ครั้งแรกต้องเปิดออนไลน์ก่อน 1 รอบ (ให้ระบบเก็บไฟล์ไว้) หลังจากนั้นเปิดจากไอคอนเล่นออฟไลน์ได้เลย · เวลามีอัปเดตใหม่ ระบบจะดึงให้เองตอนเปิดครั้งถัดไปที่มีเน็ต

## 8. วิธีเพิ่มวิชา / ข้อสอบใหม่

แก้ไฟล์เดียว: **`data/quizzes.js`** — เพิ่ม object เข้าไปใน `quizzes: [ ... ]`
(บอก Claude ว่า "เพิ่มวิชา ___ ของ ___ Exam ___ เข้าเกม" ได้เลย Claude จะแปลงจากไฟล์ quiz+เฉลย .md ให้)

โครงข้อมูล 1 วิชา:

```js
{
  id: "sheva-p1-exam2-science",     // รหัสไม่ซ้ำ
  child: "Sheva",                    // ต้องตรงกับชื่อโปรไฟล์ (Kaka/Sheva)
  grade: "ป.1", subject: "วิทยาศาสตร์", exam: 2, year: 2569,
  title: "หัวข้อบทเรียน",

  stageTitles: ["อวัยวะของเรา", "สัตว์", "พืช"],

  questions: [
    // ทุกข้อต้องมี stage (0-based) = อยู่คลังของด่านไหน · ด่านหนึ่งควรมีอย่างน้อย 9 ข้อ เกมจะสุ่มมาเล่น 6 ข้อ
    // เลือกตอบ: answer = ตำแหน่งคำตอบถูก (เริ่มนับ 0) — เกมสลับตำแหน่งตัวเลือกให้เองตอนเล่น
    { id:1, stage:0, type:"mc", prompt:"คำถาม", choices:["ก","ข","ค","ง"], answer:2, explain:"คำอธิบาย" },

    // ถ้า 2 ช่องตอบเหมือนกัน ต้องใส่คำนั้นใน options 2 ครั้ง (เด็กต้องมี chip แตะครบทุกช่อง)

    // จำแนกลงกล่อง
    { id:16, stage:1, type:"sort", prompt:"จำแนกให้ถูก",
      items:["ต้นไม้","ก้อนหิน"],
      bins:{ "สิ่งมีชีวิต":["ต้นไม้"], "สิ่งไม่มีชีวิต":["ก้อนหิน"] }, explain:"..." },

    // เรียงประโยค (คำในประโยคห้ามซ้ำกัน)
    { id:20, stage:2, type:"order", prompt:"Make a sentence", seq:["This","is","milk"], explain:"..." }
  ],

  // (เฉพาะวิชา English / Math-Inter / Science-Inter) ด่านจับคู่คำศัพท์ — 1 ชุด = 1 ด่านบนแผนที่

  vocabSets: [
    { id:"opp", title:"คำตรงข้าม", emoji:"↔️", explain:"...",
      pairs:[["big","small"],["tall","short"],["old","young"],["clean","dirty"]] }
```

## 9. วิธีเพิ่มบทเรียน "📖 อ่านความรู้ก่อนเล่น"

แก้ไฟล์ **`data/lessons.js`** — เด็กแตะด่านบนแผนที่แล้วจะมีหน้าถามก่อนว่าจะ **อ่านความรู้ก่อน** หรือ **เล่นเลย**
(บอก Claude ว่า "เขียนบทเรียนวิชา ___ ของ ___ เข้าเกม" ได้เลย Claude จะย่อจากไฟล์ `-summary.md` ให้)

- ตอนนี้เขียนครบแล้ว **ทั้ง 16 วิชา 79 ด่าน** (Exam-2 ของทั้ง Kaka และ Sheva)
- **ด่านไหนไม่มีข้อมูลในไฟล์นี้ = ไม่มีบทเรียน** แตะแล้วเข้าเล่นทันทีเหมือนเดิม (ไม่ต้องเขียนครบทุกด่าน)
- **ด่านที่ยังล็อกก็กดอ่านได้** (แต่ยังเล่นไม่ได้) — ไว้ให้ลูกอ่านเรื่องที่ยังไม่ได้เรียนที่โรงเรียนล่วงหน้า
- รางวัล: อ่านจบ**ด่านที่ยังไม่เคยอ่าน** +5 🪙 (ครั้งเดียวตลอดกาล) · **ครั้งแรกของวัน** ได้โบนัสตาม "วันอ่านติดกัน" = `10 + วันติดกัน(สูงสุด 7) × 5` 🪙 · **ไม่ให้ ⭐** เพราะดาวคือเงินที่ใช้แลกของจริง
- เหรียญจากการอ่าน**ไม่ถูกริบ**ตอนออกกลางด่าน (คนละระบบกับ session ของด่าน)

```js
window.LESSON_DATA = {
  "kaka-p2-exam2-thai": {          // ต้องตรงกับ id ใน data/quizzes.js
    "0": {                          // เลข stage (0 = ด่าน 1) ต้องมีอยู่จริงใน stageTitles
      emoji: "🔤",
      title: "อักษรสามหมู่ + ผันวรรณยุกต์",
      blocks: [
        { t:"h",  x:"หัวข้อย่อย" },
        { t:"p",  x:"ย่อหน้าธรรมดา" },
        { t:"ul", x:["ข้อ 1","ข้อ 2"] },
        { t:"table", head:["ช่อง1","ช่อง2"], rows:[["a","b"]] },   // ทุกแถวต้องมีช่องเท่าหัวตาราง
        { t:"tip", x:"เคล็ดลับจำง่าย (กล่องเหลือง)" },
        { t:"ex",  x:"ตัวอย่าง (กล่องม่วง)" }
      ]
    }
  }
};
```

> ทุกข้อความ render ผ่าน `esc()` — ใส่ HTML/markdown ในนั้นไม่ได้ (และไม่ต้องใส่) · เขียนให้สั้น อ่านจบใน 1–2 หน้าจอมือถือ ภาษาระดับ ป.1–ป.2

| ไฟล์ | หน้าที่ |
