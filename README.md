# 🎮 เกมทบทวนบทเรียน — Kaka & Sheva

เกมทบทวนบทเรียนสำหรับลูก เล่นบนมือถือ/แท็บเล็ต/คอมได้ **ฟรี 100%** ไม่มีค่า server
ตอนนี้มีครบ **สอบครั้งที่ 2 ทั้ง 2 คน** — Kaka (ป.2) 8 วิชา + Sheva (ป.1) 8 วิชา รวม 16 วิชา ~320 ข้อ
(เลือกโปรไฟล์ → เลือกวิชา → เล่นเป็นด่านๆ)

---

## 1. ลองเล่นในเครื่องก่อน (ไม่ต้อง setup)

**ดับเบิลคลิกไฟล์ `index.html`** → เปิดในเบราว์เซอร์ (Chrome/Edge) เล่นได้เลย
เหมาะกับทดสอบก่อนเอาขึ้นเว็บจริง

> เล่นในเครื่องได้เพราะข้อมูลเก็บเป็นไฟล์ `.js` (ไม่ใช่ `.json` ที่เบราว์เซอร์จะบล็อกตอนเปิดแบบ file://)

---

## 2. เอาขึ้นเว็บฟรี ให้ลูกเปิดจากมือถือได้ทุกที่

### วิธี A — Netlify Drop (ง่ายสุด ไม่ต้องสมัครก็ได้) ⭐ แนะนำ

1. เปิดเว็บ **https://app.netlify.com/drop**
2. **ลากโฟลเดอร์ `web` ทั้งโฟลเดอร์** ไปวางในหน้านั้น
3. รอสักครู่ จะได้ลิงก์ เช่น `https://ชื่อสุ่ม.netlify.app` → เปิดบนแท็บเล็ตลูกได้เลย
4. อยากเก็บลิงก์ถาวร/ตั้งชื่อเอง → สมัครบัญชีฟรี (ใช้ Google login) แล้วกด "Claim this site"

> อัปเดตเนื้อหาใหม่: แก้ไฟล์ แล้วลากโฟลเดอร์ `web` ไปวางใหม่อีกครั้ง (ทับของเดิม)

### วิธี B — GitHub Pages (ถ้ามีบัญชี GitHub อยู่แล้ว)

1. สร้าง repo ใหม่ → อัปโหลดไฟล์ในโฟลเดอร์ `web` ทั้งหมด
2. Settings → Pages → Source เลือก branch `main` โฟลเดอร์ `/root` → Save
3. ได้ลิงก์ `https://ชื่อคุณ.github.io/ชื่อ-repo/`

### วิธี C — Cloudflare Pages
คล้าย GitHub Pages เชื่อมกับ repo แล้ว deploy อัตโนมัติ (ฟรี)

**ทุกวิธีข้างบนฟรีถาวร** ค่าใช้จ่ายเดียวที่ *อาจ* มีคือชื่อโดเมนสวยๆ (~300 บาท/ปี) ซึ่งไม่จำเป็น

## 3. บันทึกความคืบหน้า (สำคัญ)

- เหรียญ / ดาว / สติกเกอร์ / streak เก็บไว้ใน **เบราว์เซอร์ของเครื่องที่เล่น** (localStorage)
- **ผูกกับเครื่อง + เบราว์เซอร์นั้น** → ถ้าเล่นคนละเครื่อง/คนละเบราว์เซอร์ จะเริ่มใหม่
- **ย้ายเครื่องได้** ด้วยโค้ดเซฟ (ดูข้อ 6) — ไม่ต้องเริ่มใหม่
- อย่ากด "ล้างข้อมูลเบราว์เซอร์/ประวัติ" เพราะจะลบความคืบหน้า

## 4. ระบบเกม (ออกแบบให้เด็กอยากเล่นทุกวัน)

| ระบบ | ทำอะไร |
|------|--------|
| 🦊 เพื่อนคู่ใจ (Buddy) | เลือกตัวการ์ตูน คอยเชียร์ตอนเล่น โตขึ้นเมื่อเล่นเยอะ |
| 🗺️ แผนที่ด่าน | หั่นบทเรียนเป็นด่านสั้นๆ ด่านละ ~6 ข้อ ผ่านแล้วปลดล็อกด่านต่อไป |
| ⭐ ดาว 1-3 ดวง | ยิ่งตอบถูกเยอะยิ่งได้ดาว เล่นซ้ำเพื่อเก็บ 3 ดาวได้ |
| 🪙 เหรียญ + คอมโบ | ตอบถูกได้เหรียญ ตอบถูกติดกัน 3 ข้อ = คอมโบ x2 |
| 🎁 ตู้สะสมสติกเกอร์ | เอาเหรียญเปิดกล่องสุ่ม เก็บสติกเกอร์ 20 แบบ (มีระดับหายาก) |
| 🔥 รางวัลรายวัน | เข้าเล่นทุกวันได้โบนัสเหรียญเพิ่มขึ้นเรื่อยๆ |
| 💪 ด่านทบทวน | รวมข้อที่เคยตอบผิด ให้ทบทวนซ้ำจนแม่น |
| 🎁 แลกของรางวัลจริง | สะสมดาว → แลกของเล่นที่พ่อแม่กด PIN ยืนยัน (ดูข้อ 5) |
| 🔊 อ่านให้ฟัง | ทุกคำถามมีปุ่มอ่านออกเสียง (ไทย/อังกฤษ auto) — ช่วยลูกที่อ่านยังไม่คล่อง |

คำถามมี 4 แบบ: **เลือกตอบ** · **เติมคำ (แตะเลือกคำ)** · **จำแนกลงกล่อง** · **เรียงประโยค (แตะเรียงคำ)**

## 5. ⭐ ธนาคารดาวความดี + แลกของรางวัลจริง (พ่อแม่ควบคุม)

เชื่อมกับระบบที่บ้าน (สะสมดาว → แลกของเล่น) ให้ลูกอยากทบทวนบทเรียน

**ดาวมาจาก 2 ทาง รวมเป็น "ธนาคารดาว" เดียว (แยกของแต่ละคน):**
1. **จากเกม** — จบด่านได้ 1–3 ดาว เข้าธนาคารอัตโนมัติ (นับเฉพาะที่ทำได้ **ดีขึ้นจริง** เล่นด่านเดิมซ้ำได้ดาวเท่าเดิมจะไม่บวกเพิ่ม = กันปั๊มดาว)
2. **จากพ่อแม่** — เข้าโหมดพ่อแม่ เพิ่มดาวเองสำหรับความดีนอกเกม (ช่วยงานบ้าน ฯลฯ)

**การแลกรางวัล:**
- เด็กเห็นยอดดาว + หลอดความคืบหน้า "อีกกี่ดาวได้ของเล่น" ตลอดเวลา (สร้างแรงจูงใจ) และกด **"ของรางวัล 🎁"** ดูได้
- ดาวครบ → กด **"ขอแลกรางวัล"** → **ต้องใส่ PIN ของพ่อแม่** ถึงจะแลกสำเร็จ (ดาวจะถูกหักออก + บันทึกประวัติ)
- ค่าเริ่มต้น: **ของเล่น 100 บาท = 10 ดาว** (ตรงกับระบบเดิมที่บ้าน)

**โหมดพ่อแม่ (ปุ่ม 🔒 ในหน้าของรางวัล — ต้องใส่ PIN):**
- **📊 สรุปจุดที่ควรติว** — โชว์วิชาที่ลูกยังพลาดบ่อย (เรียงมากสุดบนสุด) + ความคืบหน้าแต่ละวิชา จะได้รู้ว่าควรทวนเรื่องไหนเพิ่ม
- เพิ่ม/ลดดาวเอง (พร้อมเหตุผล)
- ตั้งค่ารางวัล: เปลี่ยนชื่อ / emoji / จำนวนดาวที่ใช้แลก
- ดูประวัติทั้งหมด (ได้ดาวจากอะไร แลกอะไรไปบ้าง เมื่อไหร่)
- **♻️ รีเซ็ตความคืบหน้า** ของลูกคนนี้ (ล้างด่าน/ดาว เก็บ buddy — ใช้ตอนทดสอบเสร็จ)
- เปลี่ยน PIN

**การตั้ง PIN:** ครั้งแรกที่กดแลก/เข้าโหมดพ่อแม่ ระบบจะให้ตั้ง PIN 4 หลัก จำไว้ให้ดี

> **หมายเหตุความปลอดภัย:** PIN เก็บในเบราว์เซอร์แบบธรรมดา — มีไว้ "กันเด็กกดแลกเอง" พอ **ไม่ใช่ระบบกันแฮกจริงจัง** (คนที่รู้เทคนิคเบราว์เซอร์ยังข้ามได้) สำหรับใช้ในบ้านถือว่าเพียงพอ
>
> **เด็กเก็บดาวจากเกมได้สูงสุด ~24 ดาว/คน** (8 วิชา × 3 ด่าน × 1 ดาว... ถ้าเก็บครบ 3 ดาวทุกด่าน = สูงสุด ~72 ดาว) — ตั้งราคารางวัลให้เหมาะกับที่ไหวนะครับ ปรับได้ในโหมดพ่อแม่

## 6. 📤 ย้ายเครื่อง (เซฟข้ามเครื่อง) — ไม่ต้องเริ่มใหม่

progress เก็บแยกแต่ละเครื่อง ถ้าจะย้าย iPad ↔ มือถือ ↔ คอม ใช้ "โค้ดเซฟ":

1. **เครื่องเก่า:** ของรางวัล → โหมดพ่อแม่ (ใส่ PIN) → การ์ด **"📤 ย้ายเครื่อง"** → กด **"สร้าง + คัดลอกโค้ดเซฟ"** (โค้ดจะถูกคัดลอกอัตโนมัติ หรือกดค้างเลือกคัดลอกเองก็ได้)
2. ส่งโค้ดไปเครื่องใหม่ (ผ่าน LINE/โน้ต/อีเมลตัวเอง)
3. **เครื่องใหม่:** เปิดเกม → ของรางวัล → โหมดพ่อแม่ → **วางโค้ดในช่องล่าง** → กด **"โหลดข้อมูลจากโค้ด"** (กดยืนยัน 2 ครั้ง)

> ย้ายทั้ง **ดาว/เหรียญ/ด่าน/สติกเกอร์ของทั้ง 2 คน + PIN + ของรางวัล** · การโหลดจะ**เขียนทับ**ข้อมูลในเครื่องใหม่ · โค้ดเป็นข้อความยาวๆ (base64) ไม่ใช่รหัสลับ

## 7. 📱 เพิ่มลงหน้าจอโฮม + เล่นออฟไลน์

เปิดให้เหมือนแอปจริง มีไอคอน ⭐ บนหน้าจอ และ **เล่นได้แม้เน็ตหลุด** (เหมาะเวลาเดินทาง/ก่อนนอน)

- **iPhone/iPad (Safari):** เปิดเว็บ → ปุ่มแชร์ (⬆️) → **"เพิ่มลงในหน้าจอโฮม"**
- **Android (Chrome):** เปิดเว็บ → เมนู ⋮ → **"เพิ่มลงในหน้าจอหลัก" / "ติดตั้งแอป"**
- **คอม (Chrome/Edge):** ไอคอนติดตั้ง (⊕) ในแถบ URL

> ครั้งแรกต้องเปิดออนไลน์ก่อน 1 รอบ (ให้ระบบเก็บไฟล์ไว้) หลังจากนั้นเปิดจากไอคอนเล่นออฟไลน์ได้เลย · เวลามีอัปเดตใหม่ ระบบจะดึงให้เองตอนเปิดครั้งถัดไปที่มีเน็ต

## 8. วิธีเพิ่มวิชา / ข้อสอบใหม่

แก้ไฟล์เดียว: **`data/quizzes.js`** — เพิ่ม object เข้าไปใน `quizzes: [ ... ]`
(บอก Claude ว่า "เพิ่มวิชา ___ ของ ___ Exam ___ เข้าเกม" ได้เลย Claude จะแปลงจากไฟล์ quiz+เฉลย .md ให้)

โครงข้อมูล 1 วิชา:

```js
{
  id: "sheva-p1-exam2-science",     // รหัสไม่ซ้ำ
  child: "Sheva",                    // ต้องตรงกับชื่อโปรไฟล์ (Kaka/Sheva)
  grade: "ป.1", subject: "วิทยาศาสตร์", exam: 2, year: 2569,
  title: "หัวข้อบทเรียน",
  emoji: "🔬", worldName: "โลกป่าวิทยาศาสตร์",
  questions: [
    // เลือกตอบ: answer = ตำแหน่งคำตอบถูก (เริ่มนับ 0)
    { id:1, type:"mc", prompt:"คำถาม", choices:["ก","ข","ค","ง"], answer:2, explain:"คำอธิบาย" },

    // เติมคำ: ใช้ ___ แทนช่องว่าง, blanks = คำที่ยอมรับได้ต่อช่อง, options = คำให้เลือก(รวมตัวลวง)
    { id:11, type:"fill", prompt:"สิ่งมีชีวิตต้องการ ___ และ ___",
      blanks:[["อาหาร"],["น้ำ"]], options:["อาหาร","น้ำ","หิน","แสง"], explain:"..." },

    // จำแนกลงกล่อง
    { id:16, type:"sort", prompt:"จำแนกให้ถูก",
      items:["ต้นไม้","ก้อนหิน"],
      bins:{ "สิ่งมีชีวิต":["ต้นไม้"], "สิ่งไม่มีชีวิต":["ก้อนหิน"] }, explain:"..." }
  ]
}
```

เพิ่มแล้ว: เล่นในเครื่องเช็กก่อน → แล้วลากขึ้น Netlify ใหม่
เกมจะโชว์การ์ด/โลกของวิชาใหม่ให้เด็กคนนั้นอัตโนมัติ

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|------|--------|
| `index.html` | หน้าเว็บหลัก |
| `app.js` | ตัวเกม (ระบบด่าน คะแนน สติกเกอร์ ฯลฯ) |
| `style.css` | หน้าตา/สีสัน/อนิเมชัน |
| `buddies.js` | ตัวการ์ตูน Buddy + สติกเกอร์ |

| `manifest.webmanifest` | ข้อมูลแอป (ชื่อ/ไอคอน) สำหรับเพิ่มลงหน้าจอโฮม |
| `sw.js` | Service Worker — ทำให้เล่นออฟไลน์ได้ |
| `icon-192/512.png`, `apple-touch-icon.png` | ไอคอนแอป (ดาวบนพื้นม่วง-ชมพู) |
